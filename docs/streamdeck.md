# Stream Deck plugin

The **VR Headset Manager** Stream Deck plugin drives the headset fleet from an Elgato Stream Deck.
It only uses the VRHM web API (the same one the web pages use), so it works from the VRHM PC or
from any other PC on the network.

## Install

1. Open the web interface, **Help** page, *Documentation & Resources*, and download
   **Stream Deck plugin** (`VRHM-StreamDeck.streamDeckPlugin`).
2. Double-click the file. Stream Deck (7.1 or newer) asks to install the plugin and its
   profiles: accept.
3. Stream Deck switches to the **VRHM Main** profile.
4. When Stream Deck runs on **another PC** than VRHM: select any VRHM key, and in its settings
   set **VRHM server** to `http://<VRHM PC address>:8080`. This setting is shared by every key.

## Main page (15-key Stream Deck)

One column per headset. Column 1 = first headset of the VRHM list, column 2 = the second, and so
on (the list order of the web pages).

| Row | Key | Press |
|---|---|---|
| 1 | Headset status: name, state, battery | Opens the headset page |
| 2 | Recording state (can be changed, see below) | **Press**: snapshot of the stream. **Hold**: recording on / off |
| 3 | Timer of the headset | Start / pause / resume. **Hold**: stop and reset |

Status colours: grey = off, amber = answers ping but no ADB, green = ready, blue = live (capture
running), purple = capture starting. A red frame and dot = recording. While live, the key shows
the icon of the running game instead of "LIVE" when VRHM has one. A headset **on battery** (not
plugged) blinks: orange frame, battery level in bold red; the frame is red when the battery is
under the low level of the VRHM configuration (*Monitoring > headset battery warning level*).

Row 2 can do something else: select the key, and in its settings pick another **Command**, for
example *Capture start / stop* or *Snapshot to recordings folder*.

## Headset page

Opened by a status key; every key acts on that headset.

| | | | | |
|---|---|---|---|---|
| Home | Status (press = refresh) | Reset UI view | Apps | Close running app |
| Volume - | Volume + | Brightness - | Brightness + | Capture start / stop |
| Settings | Capture profile | Send to kiosk | Reboot (hold) | Shutdown (hold) |

- **Settings** (gear) opens a page with the headset settings of the web *Configure* window,
  read from the headset when the page opens (a few seconds):

  | | | | | |
  |---|---|---|---|---|
  | Back | Guardian on / off | Guardian setup | Side double tap on / off | Wide hand tracking on / off |
  | Keep awake on / off | Sharpening off / CAS / MQSR | Refresh rate (cycle) | OTA updates allowed / blocked | Re-apply after reboot |
  | Reload | | | | |

  Green = on. *n/a* = the headset cannot report or change it (e.g. a Pico). Most of these last
  until the headset restarts; turn on *Re-apply after reboot* to have VRHM put them back.

- **Capture profile** (shows the current view and eye) opens a page: top row = Back, eye **Left**, **Right**, **Merged** (only on
  models with an eye merge calibration; merged sets 30 fps when the profile asked for more),
  rows 2 and 3 = one key per view of the headset model. Each view key draws the shape of the
  picture it sends (square, portrait, wide rectangle...); fullscreen is a wide rectangle
  holding the two eyes. The current eye and view are blue with a green
  frame. The page stays open so both can be changed; Back returns to the headset page.

- **Apps** opens a page with the favourite apps of the headset (set in the web Apps manager).
  Press one to launch it.
- **Send to kiosk** opens a page with the kiosk screens. Press one to show the headset's video
  page on it.
- **Reboot** and **Shutdown** need a long press, to avoid an accident.
- Volume and brightness change by 10 % per press (setting *Step*).

## Snapshot

The *Snapshot* command saves one picture of the stream (what viewers see) as a PNG in the
recordings folder: `<record folder>\<date>\<headset>\<headset>_<time>.png`. When the headset
is not streaming, a direct capture of the full headset picture is taken instead (a few seconds).
Snapshots are not listed on the Recordings page.

The same action exists in the console (headset panel, key `P`) and in the API
(`POST /api/headset-snapshot` with `{"id": <headset id>}`).

## Building the plugin (developers)

Sources: `StreamDeck\vrhm-plugin\` (TypeScript, Elgato SDK). Build:

```powershell
.\scripts\Build-StreamDeckPlugin.ps1            # build + pack to website\headset-toolbox\
.\scripts\Build-StreamDeckPlugin.ps1 -Link      # also link into Stream Deck for testing
```

The build runs in `%LOCALAPPDATA%\VRHM\streamdeck-build` (not on the shared drive). Template
profiles are generated by `StreamDeck\tools\New-VrhmProfiles.ps1` and the static icons by
`StreamDeck\tools\New-VrhmPluginIcons.ps1`.
