Download Kiosk Launcher
Windows - standalone kiosk agent (easiest)

A single, self-contained executable - nothing to unzip. Copy it to the kiosk PC and double-click Start-Kiosk-ADVANCED.exe - it asks for administrator rights, starts the kiosk browser, and finds this server on the network automatically (nothing to type). The first run also extracts its own Start-KioskAgent.ps1 source next to itself, so it stays inspectable and editable afterward.

Download kiosk agent (.exe)

On a routed network (server not on the kiosk's own subnet), pass the address directly instead of relying on the scan: Start-Kiosk-ADVANCED.exe -ServerIp 10.0.5.12. For the original casting-only launcher, see Setup Scripts - Basic below.

Setup Scripts - Advanced (manual)

The individual scripts, if you would rather not use the standalone .exe (or need the Linux one). On top of opening the firewall and launching Chrome in kiosk mode, the advanced launcher finds this server automatically, reports the PC's computer name, OS and network link type back here, lets you reboot or shut the PC down remotely, and restarts the browser by itself if it crashes. It stays running - keep its window open.
