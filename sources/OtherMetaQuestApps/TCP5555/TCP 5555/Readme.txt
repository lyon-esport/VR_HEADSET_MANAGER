[ENG]
1) To install the .apk and enable the ADB Wi-Fi connection :
	- Make sure the only Android device plugged into your computer is your headset
	- Run the INSTALLATION.bat file automatically install the apk and automatically enable ADB Wi-Fi connection
	/!\ You may need to accept the USB debugging RSA key (click on always authorize)

2) To only enable ADB Wi-Fi Connection :
	- Run the ADB_WIFI_CONNECTION.bat file
